## 📂 核心观测档案 (Core Files)

### 🧙‍♂️ [03-00 宋清思](./03-00%20宋清思.md) —— 群星魔女 / 超越世界之人

- **状态**：已脱离原始位面（SQS-ZX-00S），常驻于世界之外的“魔法工房”。
- **核心特性**：
    - **🧬 切片系统**：拥有五个不同时期的灵魂/身体切片，心态跨度从“可爱萝莉”到“淡漠神明”。
    - **🌐 清思网络**：支撑全位面感知的瞬时精神互联信道。
    - **📦 魔方宇宙**：超大规模的模拟与存储空间，灵感源自《崩坏：星穹铁道》模拟宇宙。
- **🎮 战绩摘要**：虽然拥有神格，但手操《群星》或《文明》时极易被本地人欺负到破防。

### 🗡️ [04-00 温芙凝](./04-00%20温芙凝.md) —— 永生的白发魔剑士

- **状态**：因 1200 年灵魂受损导致时间反噬，呈现长生白发态。
- **核心经历**：
  - **🕰️ 命运偏离**：本是冒险者，却因清思的“地城实验事故”被迫开启千年的守望。
  - **🛡️ 组织基石**：1477 年联手蓝龙秦霜溟建立星球守护组织 MoonDrop。
- **现状**：2026 年面临严重的灵魂过载与记忆缺失，正在（物理意义上）被后辈黎希宁“深度关照”中。

### 🐲 [04-01 秦霜溟](./04-01%20秦霜溟.md) —— 星球代理人 / 远古蓝龙

- **状态**：位面管理组织在 SOL-3 的代理人，清思的“受害者”与孽缘协作人。
- **核心职能**：
  - **❄️ 元素镇压**：负责处理位面裂隙（如卡纳尔冰原、 1755 年里斯本灾难）及元素暴动。
  - **🏢 组织运营**：MoonDrop 的幕后核心，引导文明在规则内延续。
- **🏢 秩序维持**：MoonDrop 的幕后运营者，对清思的“奇思妙想”持有高度警戒。

### ⌛ [04-02 黎希宁](./04-02%20黎希宁.md) —— 时间解放者 / **先祖绝对领地拥有者**

- **状态**：**家族认同感 0%**，**对先祖攻略度 100%**（自称）。
- **核心特性**：
  - **🏹 致命深情**：对芙凝一见钟情。跨越千年历史，只为带先祖去坐旋转木马。
  - **✂️ 事件删除**：拥有绝对的时间权限，能够通过“揉搓时间”达成逻辑闭环。
  - **🚨 心理活动**：包括但不限于盯着昏睡的先祖脸红、借口换衣服进行“观察”、以及物理消灭任何碍事的终端。
- **备注**：**危险级人物**。清思和霜溟一致公认的“芙凝解放者”。

- **📅 1200年**：**【命运偏离点】** 芙凝误入地城，白发契约达成，清思发放“补偿”。

- **📅 2026年**：**【解放与接管】** 希宁正式登场。在游乐场的摩天轮上，接管了先祖的未来。
